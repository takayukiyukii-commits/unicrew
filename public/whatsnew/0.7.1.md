# UNICREW 0.7.1 の変更

AIオフィスで、**どこまで自動で進めるかを選べる**ようになりました。
許可や確認が要るときの**通知から、そのまま返事ができます**（Windows）。

## ⚙️ 自動で進める度合いを、3段から選べます

社長からの指示の箱にある3つのボタン、または会社の設定から切り替えます。会社ごとに覚えます。

- **毎回聞く**（これまでどおり）：社員が道具を使う許可・できあがりの確認・質問のたびに、あなたの返事を待ちます
- **ほぼ全自動**：社員が道具を使う許可は、聞かずに通します。できあがりの確認と質問は、あなたの返事を待ちます
- **完全自動**：道具の許可は聞かずに通し、できあがりの確認は OK として進め、質問はおすすめの案で進めてもらいます（確認と質問は、1つの仕事でそれぞれ8回を超えるとあなたを待ちます）

「ほぼ全自動」「完全自動」のあいだは、ファイルの書き換え・消す操作・外への送信を含むコマンドも、アプリは止めません。大事なフォルダは写しを取っておいてください。通した操作は右の「通知」に残ります。

## 🔔 通知のボタンで、そのまま返事ができます（Windows）

社員が許可や確認を待っているときの通知に、ボタンが付きました。

- 許可を待っているとき：「許可する」「許可しない」（内容が長くて通知に入りきらないときは、「開いて全部読む」だけが出ます）
- できあがりの確認を待っているとき：「OKを出す」「開いて確かめる」

「許可する」「許可しない」「OKを出す」を押すと、画面で押したのと同じように進みます。macOS と Linux は、これまでどおりの通知です。

## 🚶 社員の歩き方の無駄を減らしました

- まっすぐ歩ける所は、角を回らずに歩きます
- 席を立つとき、反対側の角まで行って引き返すことがなくなりました
- 資料の棚へ見に行く回数を減らしました（40秒に1回まで）
- 待っているあいだに休憩へ歩くのは、1分半に1人までにしました
