# UNICREW 0.6.3 の変更

会話を**ファイルに保存**するようにし、使い続けても保存できなくなる上限を無くしました。
ターミナルの**コピー**、**リンクのクリック**、**音声入力のボタン**も使いやすくしています。
古い Mac で**ボタンが反応しない**問題も直しました。

## 💾 会話をファイルに保存するようにしました

これまでは、すべての会話をアプリの中の小さな保存領域にまとめて保存していました。使い続けると容量がいっぱいになり、保存できなくなることがありました。

- 0.6.3 からは、会話ごとに1つのファイルとしてパソコンに保存します。容量の上限はありません
- 初めて起動したときに、これまでの会話を自動でファイルへ移します。元の保存は控えとして残してから移します
- 保存に失敗したときは、どの会話か、何が残っていて何が失われるおそれがあるかをお知らせします
- アプリを閉じる直前の変更も、書き切ってから終わります

## 📋 ターミナルからのコピーで、余計な空白が付かなくなりました

Claude Code の文章をターミナルからコピーすると、行の終わりや左側の空白まで一緒にコピーされていました。

- 行の終わりの空白と、全体の左側の余白を取り除いてコピーします
- コードの字下げ（Python や YAML など）は、そのまま残します
- 画面の幅で折り返された文章は、1つの文につなげてコピーします

## 🔗 URL やファイルのパスを、どこを Ctrl+クリックしても開けるようにしました

Claude Code の出力にある URL やパスを Ctrl+クリックしたとき、文字の場所によって開いたり開かなかったりしていました。

- どこをクリックしても、URL は既定のブラウザで、ファイルはエディタで開きます
- 安全のため、ネットワーク上の共有フォルダを指すリンクは開きません

## 🎙️ 音声入力のボタンを、ターミナルごとに付けました

ターミナルを並べているとき、それぞれの見出しにマイクのボタンが付きます。押したターミナルに、話した言葉が入ります。

## 🍎 古い Mac で、ボタンが反応しない問題を直しました

古い Safari が入った Mac で、画面は表示されるのにボタンが反応しないことがありました。

- 古い Safari でも動く形にしました（Safari 15.4 以上が必要です）
- Safari が古すぎるときは、更新のしかたを画面にお知らせします
- この問題が起きていた方は、自動更新が届かないため、最新版をダウンロードして入れ直してください
