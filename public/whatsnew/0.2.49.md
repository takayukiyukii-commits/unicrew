# UNICREW 0.2.49 の新機能

## 🩹 「インストールボタンを押しても何も起きない」を修正

初回セットアップの **Claude Code / Codex CLI のインストールボタン**が、押した直後に
元の状態へ戻ってしまい、進捗も失敗理由も表示されない問題を修正しました。

実際にはインストールは裏で走っていたのですが、画面上は「無反応」に見えるため、
何度も押してしまい、**インストーラ同士が一時ファイルを取り合って失敗する**ことが
ありました（Windows で `The process cannot access the file because it is being
used by another process` というエラーになります）。

- インストール中は進捗が1行ずつ表示され、完了するまでボタンは押せません
- 失敗したときは、その場で**手動コマンド（コピーボタン付き）**とサポート導線が出ます
- 同時に2つ以上のインストールが走らないよう、アプリ側でもロックをかけました

## 🔧 インストール経路を公式の推奨に統一

Windows は `claude.ai/install.ps1`、macOS / Linux は `claude.ai/install.sh` を
第一経路にしました（管理者権限も Node.js も不要で、以後は自動更新されます）。
失敗したときだけ winget / brew / npm にフォールバックします。

macOS / Linux では、インストーラが正常終了しても CLI が見つからない場合に
「成功」と表示されてしまう問題も直しました。
