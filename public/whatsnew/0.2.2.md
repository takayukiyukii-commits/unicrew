# UNICREW 0.2.2

英語UIの全面対応と、新しい会話モーダルの選択バグ修正。

---

## 新機能

### 言語切替（日本語 / English）
- **初回起動時に言語ピッカー** が表示されるようになりました。あとから **設定 → 言語 / Language** で切り替え可能。
- ほぼすべてのUI文字列（サイドバー、ウェルカム画面、ウォークスルー、設定モーダル、チャット、各種ダイアログ）を双方向対応。
- OS の言語設定から自動推測（日本語OSは ja、それ以外は en にフォールバック）。
- 既存ユーザーの自動アップデート時は **現在のロケール（日本語）が引き継がれます**。

---

## 修正

### 「新しい会話」で normal キャラの起動 AI が誤って上書きされていた問題
- **OpenCode（normal）/ Qwen（normal）/ Kimi（normal）** を選んだとき、上部の「どのAIで起動」タブ（Claude）が誤って適用され、表示が `Kimi (Claude)` のようになっていた問題を修正。
- 「どのAIで起動」タブの選択は、**おまかせ以下の人格テンプレ（CEO / CDO / CMO / 等）にのみ反映** されるよう本来の動作に戻しました。
- normal 系テンプレ（Claude / Codex / OpenCode / Qwen / Kimi）は常に自身の CLI で起動します。

### 右ペイン「モデル」セクションのラベル明確化
- **モデル（claude）** と明示。Claude スロット専用の設定であることが一目でわかるように。

### normal テンプレの重複表示を解消
- 参加者プルダウンや「キャラを選ぶ」モーダルで **Claude（normal）（Claude（normal））** のように同じ文言が二重表示されていた問題を修正。
- 内部的に `name` と `roleTag` が同一だったのが原因。`roleTag` を `Claude Code（Anthropic公式CLI）` / `Codex CLI（OpenAI公式・第二意見）` に整理し、OpenCode / Qwen / Kimi と同じ「プロバイダ説明」ラインに揃えた。

---

## 内部変更

- `lib/i18n.ts` 新設。`useTranslation()` フックで全コンポーネントが locale 変更を即追随。
- 議論モードプリセット（`CONFERENCE_PRESETS`）を i18n factory 化（`nameKey` / `descKey` で参照）。
- `components/CharacterPickerModal.tsx`：`NORMAL_TEMPLATE_IDS` に opencode / qwen / kimi の normal を追加。
- 配布サイトは **ja / en / zh-Hans** の3言語対応を配布開始時点までに用意予定。
