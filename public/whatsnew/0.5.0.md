# UNICREW 0.5.0 の変更

ターミナルを「文字が流れる箱」から**開発の道具**に変えました。
探せる・戻れる・AI に渡せる・またぎ直せる。あわせて、0.4.0 で入っていた変更もここにまとめます。

## 🔍 ターミナルの中を検索できる（Ctrl+F）

- 5万行のスクロールバックから探して、**何件目 / 全何件**が出ます。Enter で次、Shift+Enter で前
- これまで `Ctrl+F` は裏に隠れているチャットの検索が動いていて、ターミナルでは**何も起きませんでした**。直しました
- `Ctrl+K` も同じで、シェルの「行を消す」とコマンドパレットが同時に出ていました。ターミナルではシェル側が優先されます

## 📌 いま出した指示が、流れても上に残る

- 送った指示をターミナルの**いちばん上に貼り付けて**おきます。長い応答が流れても「何を頼んだか」が消えません
- クリックで全文表示／折りたたみ。いらないときは隠せます

## 🤖 ターミナルの中身を AI に渡せる

- 文字を選ぶと「**選択をAIに送る**」が出ます。押すとチャットに切り替わり、作業フォルダと CLI 名を添えて渡します
- これまではコピー → 画面を切り替え → 貼り付けの3手が必要でした

## 🎚️ 「どれくらい考えるか」を選んでターミナルを開ける

- ＋AI メニューで **Claude Code / Codex / Grok / Kimi** の**思考の深さ**を選べます（low / medium / high / xhigh / max）
- 既定は「**おまかせ（指定しない）**」＝これまでと**まったく同じ**起動です
- 選んだ深さはペインのバッジに出ます。CLI 側が受け付けなかった場合はバッジに取り消し線が付きます（表示だけ立派で中身が既定、を防ぐため）

## ▶️ このフォルダで動かせるコマンドを一覧から実行

- `package.json` の scripts / `Makefile` / `Cargo.toml` を読んで、実行できるものを一覧にします
- クリックすると**新しいシェルのペイン**が開いてそのまま走ります。npm / pnpm / yarn / bun はロックファイルから自動で判別します

## 📣 同じ指示を複数の AI へ一斉送信

- 下の入力欄に打って Enter で、**選んだターミナルにだけ**同じ指示が飛びます
- 対象は表示中のページのものだけ。1つずつ外せます（同じ質問を Claude と Codex に投げて見比べる用）

## 🧩 画面の使い勝手

- **前回の構成を復元**します。ページ・ペイン・どの CLI か・作業していた場所・分割幅まで戻ります
- ペインの**境界をドラッグ**して幅と高さを変えられます
- ペインの**最大化**（ボタン、またはヘッダーをダブルクリック）。他のターミナルは動いたままです
- 見ていないページで出力があると、タブに**印**が付きます（終了したときは赤）
- **ダークテーマ**を選ぶとターミナルも暗くなります（これまでターミナルだけ真っ白でした）
- **Ctrl+ホイール**で文字の大きさを変えられます（全ペインに反映・次回も覚えています）

## ⚠️ 終了したことが分かるようになりました（不具合修正）

- ターミナル内のプロセスが終わったとき、**終了コード**と**再起動ボタン**が出ます
- これまで Windows では、終了しても**画面に何も出ませんでした**（終了の通知が一度も届いていませんでした）。根本から直しました

## 🔌 シェル統合（入れた人だけ効きます）

- ターミナル上部のプラグのボタンから、**設定に貼る数行**をコピーできます（bash / zsh / PowerShell）
- 入れると、直前のコマンド・**終了コード**・所要時間・`cd` の移動先が UNICREW に伝わり、
  「**直前のコマンドの出力だけ**を AI に渡す」ボタンが使えます
- UNICREW が皆さんの設定ファイルを書き換えることはありません。入れなくても今までどおり動きます

## 🗂 AI ごとの作業場でターミナルを開ける

- 2人以上の AI を動かすと切られる作業場（git worktree）を、＋AI メニューからそのまま開けます

## 0.4.0 で入っていた変更（お知らせが出ていなかった分）

- **AI ごとに作業場を分ける** — 2人以上を並べるとき、AI ごとに独立した git worktree を切ります。取り込みは merge かパッチ
- **変更の差分ビュー** — AI が変えたファイルの一覧と ± 行数、左右比較（読み取り専用）
- **チェックポイント／巻き戻し** — 自分の発言の直前の状態に**ファイルだけ**戻します（会話は消えません）
- **相互監査** — `/監査` で、実装したのとは**別の会社の AI** が読み取り専用で点検します
- **サイドチャット／会話検索** — `/side` で本線の文脈を持ったまま脇で相談。`Ctrl+Shift+F` で全スレッド検索
- **リモート受付の廃止** — スマホからの遠隔実行は機能ごと取りやめました。当社サーバーへ送るのは匿名の起動情報3項目だけです
