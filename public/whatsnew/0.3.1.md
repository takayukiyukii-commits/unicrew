# UNICREW 0.3.1 の変更

## 🔌 プラグイン紹介を拡充

アドオン画面のプラグイン紹介に、コミュニティ製の便利なプラグインの
**日本語説明と「何ができるか」**を追加しました。

- senior-frontend（実務水準の React / Next / TypeScript 実装）
- test-writer-fixer（テストの自動作成・修復）
- ship（コミット→PR→本番までの一連の流れ）
- theme-factory（資料・スライド・LP 向けのプロ品質テーマ10種）ほか

Anthropic 公式プラグインと合わせて、掲載カタログの説明が一通り日本語で読めます。

## 🛡️ プラグイン/インストール機能をダブル監査（Claude×Codex×3回）

この機能はこれまで監査していなかったため、リリース前に独立2系統×3観点で
点検し、見つかった9件を修正しました（実害があるもののみ）。

- **安全性**: マーケットプレイス追加の入力欄に、想定外の場所を指す値を入れると
  意図しないフォルダへ書き込めてしまう問題を修正（入力を厳格に検証）
- **壊れにくさ**: プラグイン一覧の設定ファイルを更新する途中で失敗しても
  ファイルが壊れないよう、書き込みを「全部書けてから差し替える」方式に変更。
  マーケットプレイスの取得が途中で失敗したときも、壊れた残骸を残さないようにしました
- **見やすさ**: アドオン一覧の読み込みに失敗したとき、これまでは「0件」と
  表示されて気づけなかったのを、失敗を知らせるようにしました。
  Codex の MCP を削除するボタンが出ていなかったのも修正しました

> 機能そのものの使い方は 0.3.0 から変わりません。安心して使えるようにするための更新です。
