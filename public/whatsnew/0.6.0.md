# UNICREW 0.6.0 の変更

チャットの**利用量の減らし方**、ターミナルの**モデル一括切替**、作業が終わったときの**自動プレビューと通知**、
初心者モードの**進み具合の表示**、**音声入力**を入れました。

## 💸 チャットが、ターミナルより多く利用量を使っていました

チャットは、AI のモデルを「Opus 4.7」「Sonnet 4.6」のように**古い版で固定して**呼んでいました。
ターミナルは版を指定しないので、いつも最新版で動いています。同じ質問で比べると次のとおりでした。

| | チャット（古い版） | ターミナル（最新版） |
|---|---|---|
| Opus | 1トークンあたり約1.25倍・思考の深さ「とても深い」 | 標準 |
| Sonnet | 1トークンあたり約1.5倍・思考の深さ「深い」 | 標準 |

- 0.6.0 からは版を書かずに **「Opus」「Sonnet」「Haiku」** で呼びます。いつも最新版が選ばれます
- 前の版で保存した会話やキャラクターも、自動で新しい呼び方に直ります
- モデル欄の表記も「常に最新版」と分かる言い方に変えました

## 🔀 ターミナルのモデルをまとめて切り替え

ターミナル上部のチップのボタンから、表示中のページにある **Claude Code 全部のモデル**を一度に切り替えられます。

- 会話はそのまま続きます
- **許可の確認画面が出ているターミナルには送りません**（Enter が「はい」を押してしまうため）
- Claude 以外の AI は、それぞれの画面で選ぶ方式なので対象外です（メニューに数が出ます）
- Claude Code の仕様で、次に開く新しいセッションの既定もそのモデルになります

## 🖼️ 作ったものを自動でプレビュー

AI が Web ページ・文章（Markdown など）・画像を作ると、**プレビュー窓が自動で開きます**。

- 左に「どのフォルダに何を作ったか」の一覧、上にファイルのフルパス
- 「フォルダ」ボタンでエクスプローラーが開きます。パスのコピーもできます
- 文章はこの窓の中でそのまま読めます
- 入力中の欄からカーソルは奪いません。設定 →「作業が終わったとき」で止められます

## 🔔 作業が1つ終わるたびにお知らせ

- チャットの作業が終わったとき、ターミナルの AI が働き終えて止まったとき（確認待ちを含む）に、**パソコンに通知**します
- 見ていない間に終わった作業があると、**通知領域とタスクバーのアイコンに赤い印**が付きます
- **× で閉じても通知領域に常駐**します。終了するときは、通知領域の UNICREW アイコンを右クリック →「UNICREW を終了」
- どれも設定 →「作業が終わったとき」で切り替えられます

## 📋 初心者モードで「いま何をしているか」を表示

これまでは AI が考えている間「…」しか出ませんでした。

- 「b.md を書いています」「✓ a.md を作りました」「段取り 2/5 完了」のように、**進み具合を日本語で随時**出します
- コマンドの名前ではなく、「必要な部品をインストールしています」「テストを動かして確かめています」のように**何のための作業か**で表示します

## 🎤 音声入力

チャットの入力欄の横と、ターミナルの上部に**マイクボタン**を付けました。

- Windows 標準の音声入力を呼び出します。**API キー不要・追加料金なし**・日本語に対応
- チャットは入力欄の末尾に、ターミナルは最後に触ったターミナルに文字が入ります
- 別のアプリに文字が入らないよう、UNICREW の窓を前に出せなかったときは始めません
- macOS は fn キーを2回押す音声入力をお使いください
