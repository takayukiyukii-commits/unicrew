# UNICREW 0.3.0 の新機能

## 📱 スマホから、このPCのAIを操作（公式リモコン）

「ファイル」メニュー →「スマホから操作（公式リモコン）…」を追加しました。

- **Claude タブ**: Claude 公式の Remote Control を1クリックで起動し、接続用の
  QR コードを表示します。スマホの Claude アプリやブラウザ（claude.ai/code）から、
  **このPCで動いている Claude Code セッション**にそのまま接続できます。
  実行もファイルもこのPCの上のまま。机で始めた作業をソファから続けられます
- **Codex タブ**: Codex 公式の Remote Control を起動し、ChatGPT アプリに入力する
  ペアコード（例: `4VPU-CU3B`）を発行します
  ※ Codex 公式の制約により macOS / Linux 版のみ（Windows では案内を表示します）
- モーダルを閉じてもサーバーは動き続けます。使い終わったら「停止」を押してください

## ⚫ Grok（xAI）が仲間入り — 4人目のAI

xAI 公式の Grok CLI を、チャット・N-way 会議で使えるようにしました。

- 設定画面の「オープン/ローカル」から**ワンクリックでインストール**できます
  （npm 配布・Windows / macOS / Linux 全対応）
- 認証は Grok CLI 側で完結（`grok login` のデバイスコード方式）。
  UNICREW がキーを預かることはありません
- モデルは grok-4.6（コンテキスト50万トークン）
- Grok CLI は初期設定のままだと Claude Code の MCP 設定やフックを自動で
  取り込んで動かします。UNICREW から起動する場合はこれを無効化してあり、
  **応答が約15倍速くなり、意図しない連携も起きません**（実測: 69秒→4.7秒）

## ◼️ Cursor も仲間入り — 5人目のAI

Cursor 公式の Agent CLI（cursor-agent）にも対応しました。

- GPT / Claude / Gemini などをモデル指定で切り替えられるマルチモデルのエージェントです
- 会話の続きは Cursor 側が覚えているので、2ターン目以降は差分だけ送られて速い
- 認証は `cursor-agent login` か CURSOR_API_KEY（CLI 側で完結）
- ※ Windows ネイティブ版が存在しないため、Windows では **WSL に cursor-agent を
  導入してあれば自動で WSL 経由で起動**します（macOS / Linux はネイティブ）

## 🖥️ ターミナルが「Claude 専用」を卒業

ターミナルのペインヘッダに「＋AI」メニューを追加しました。

- Codex / Gemini / Grok / OpenCode / Qwen / Kimi / Goose の対話画面（TUI）を、
  Claude と同じターミナル基盤でそのまま開けます
- 最大6ペインなので、**複数のAIターミナルを並べて同時に**使えます

## 🛡️ 品質: リリース前にダブル監査×3回

新機能すべてを、実装者（Claude）と独立した監査役（Codex）の2系統×3観点で
監査してから出荷しています。今回見つけて直したもの:

- ターミナルを素早く開き直したときに、まれに入力・停止が効かなくなる競合
- Cursor / Gemini の「停止」ボタンが実行中の処理を実際には止めていなかった問題
- ワークスペース未選択のまま Cursor が意図しないフォルダを信頼してしまう穴
