# UNICREW 0.2.0

## マルチ AI ランチャーへの進化

UNICREW が「Claude / Codex を束ねるツール」から、

**サブスクでも、ローカルでも、複数 AI を同時に動かせるランチャー**

に進化しました。

---

## 1. ACP（業界標準）対応で AI が一気に増えた

業界標準 **Agent Client Protocol** に対応した OSS エージェントが、UNICREW から直接使えます。

- **Goose** — Block 製、Apache-2.0
- **OpenCode** — sst 製、MIT。ローカル Ollama でも動く
- **Codex-ACP** — Zed Industries 製、Apache-2.0。BYOK で OpenAI を呼ぶ
- **Kiro CLI** — AWS 製、Bedrock backed
- **Kimi Code CLI** — Moonshot AI 製、ACP ネイティブ、OAuth login

Claude / Codex / Gemini と合わせて **9 種類**のエージェントが、

同じ画面・同じ会話 UI で使えます。

---

## 2. Qwen Code 追加で議論モード 4 極化

OSS の **Qwen Code**（Alibaba、Apache-2.0、Claude Code fork）を統合しました。

議論モードプリセットに **「4 極議論（西側 3 社 × Qwen）」** を追加。

Anthropic / OpenAI / Google から独立した中立第三者が入ることで、

学習データの偏りが分散して議論が深くなります。

---

## 3. 1 分で始める — 完全自動 Free モード

「**まずは無料で試す**」ボタン 1 つで、API キー不要の環境が自動セットアップされます。

1. Ollama 本体を winget でインストール
2. `qwen2.5-coder:7b` をダウンロード
3. OpenCode CLI を npm でインストール
4. OpenCode 単独スレッドを自動起動

**API キー 0 円・サブスク不要**で UNICREW の本質体験が完走できます。

---

## 4. 議論モードがプリセット 7 種でワンクリック

「プリセットから議論を始める」から、用意済みのキャストを選ぶだけで議論が開けます。

- **定番 3 社議論** — Claude / Codex / Gemini
- **4 極議論** — 西側 3 社 × Qwen
- **コードレビュー対決** — Claude × Codex
- **UNI 製品マーケ議論** — CMO / CSO / CDO
- **Claude 内部対話** — C-suite
- **ACP 3 社議論** — Goose / OpenCode / Codex-ACP
- **東西 ACP 議論** — OpenCode × Kimi × Goose
- **完全無料議論** — OpenCode × 2 + Goose（Free モードで動く）

---

## 5. UI が増えても破綻しない設計

プロバイダ数が 3 → 9 に増えても、画面が縦長化したり色種が爆発しないよう、

「**UI 複雑化を避ける 5 原則**」を AGENTS.md に明文化しました。

- SettingsModal はカテゴリ別 accordion
- WelcomeLanding は単一 CTA + 詳細 details
- 初見ユーザーが迷わないよう再設計

---

## 6. その他の改善

- **タブ式エディタ** — エクスプローラーからファイルをタブで開ける（別ウィンドウ）
- **Command Palette** — ⌘K / Ctrl+K でキャラ / モード / ワークスペース切替
- **Welcome Walkthrough** — 初回起動から最初のメッセージまで誘導
- **What's New モーダル** — このページ自体がそれ
- **Trust Prompt** — ワークスペース信頼の明示確認
- **Observability** — 起動時間・spawn 失敗率の自己診断

---

## 法的事項

UNICREW は、Anthropic / OpenAI / Google / Alibaba / Moonshot AI / Block / sst / Zed Industries / AWS とは無関係の独立したクライアントアプリです。

各社の商標・モデル・サービスは各社に帰属します。

ACP（Agent Client Protocol）は Zed Industries 主導のオープンプロトコル（Apache-2.0）です。
