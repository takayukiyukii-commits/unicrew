# UNICREW 0.1.0 — はじめてのリリース

UNICREW を使い始めてくれてありがとうございます。
このバージョンで体験できることをまとめました。

## 主な機能

- **Pure CLI Conductor**
  Anthropic 公式 `claude` と OpenAI 公式 `codex` を subprocess として束ねます。
  Pro / Max のサブスクリプションがあればそのまま動きます。

- **キャラクターと人格 12 種**
  役割（systemPrompt）と人格（口調）を分離して持てるので、
  「ガチ実装は厳しめ、雑談はゆるめ」を 1 クリックで切替えられます。

- **並列モード / 議論モード**
  Claude と Codex を同時に走らせて並べたり、
  互いの回答を見て改善する議論ループを回せます。

- **エクスプローラーとタブ式エディタ**（New）
  サイドバーから「エクスプローラー」を開くと、ワークスペースのファイルが一覧で見えます。
  ファイルを選ぶと別ウィンドウのエディタで開き、2 つ目以降はタブで追加されます。
  会話画面は邪魔されません。

- **Command Palette（⌘K / Ctrl+K）**（New）
  キャラ切替・モード切替・ワークスペース切替・スレッド検索を 1 か所で。
  メニューを探さずに済みます。

- **Welcome Walkthrough**（New）
  Claude → Codex → 最初のキャラ選択を 3 ステップで誘導。
  迷子にならず最初のメッセージまで辿り着けます。

## ヒント

- ⌘K（Mac）/ Ctrl+K（Win）でいつでも Command Palette を開けます。
- サイドバー下の「エクスプローラー」ボタンでファイルツリー表示を切替えられます。
- 議論モードは「会話の途中で深掘りしたい」ときに便利。Picker から選べます。
