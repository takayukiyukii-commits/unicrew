# UNICREW 0.2.1

主にユーザー体験の細かい改善と、自動アップデート機構の追加。

---

## 新機能

### あなたのプロフィール
- 「あなた」アバターをカスタマイズ可能に。**設定 → あなたのプロフィール** から：
  - 表示名（既定「あなた」）
  - アバター画像（「画像を選ぶ」 or **画像をアバターにドラッグ&ドロップ**）
  - 画像が無い時の 1 文字（絵文字 / 漢字）と背景色
- 過去の自分メッセージにも即反映されます。

### ファイル名のCtrl+Click 起動
- AI の応答内にファイル名（`NOTE_xxx.md` 等）が登場したら、**Ctrl+Click（Mac は Cmd+Click）** で別ウィンドウのエディタが開きます。
- 通常クリックでは何もせず、テキストとして選択できるので誤操作しません。

### 自動アップデートチェック
- Claude / Codex CLI、Claude プラグイン、git 連携スキル、Codex marketplace の最新版を **1 日 1 回自動チェック**。
- 「機能の追加」ページ上部に更新ありバナーが出るので、ボタン 1 つでまとめて適用できます。
- **オプトイン**：設定で「検出した更新を自動適用」を ON にすると、確認なしでバックグラウンド適用も可能。

---

## 改善

- **新しい会話のフォルダピッカー**が、最後に開いていたフォルダから始まるように。
- **非 Claude プロバイダ**（Codex / Gemini / OpenCode 等）使用時、右サイドバーの「モデル」セクションを自動で隠して混乱を防止。
- **CEO テンプレートが 2 つ表示される問題**を修正。既に複製済みのテンプレは隠れます。
- **設定モーダルのキャラ一覧**で、テンプレを複製済みかどうかを `clonedFrom` で記録するようになりました。
- **応答が止まったまま動かないケース**を検知して停止ボタンをパルス表示（アンバー色 + 「強制停止」表記）。
- **resume 失敗（claude --resume で死んだ sid を引いて固まる）** を自動回復するウォッチドッグを追加。30 秒以上ブロック 0 のまま反応なしなら、自動でセッションをリセットして再送します。

## 内部変更

- `AppSettings` に `userDisplayName / userAvatarPath / userEmoji / userAccentColor / autoCheckAddonUpdates / autoApplyAddonUpdates` を追加。
- Rust 側：`check_addon_updates` / `apply_addon_update` / `save_avatar_bytes` を追加。
- ファイル名リンク化用に `lib/file-link.ts` を新規追加。
