# UNICREW 0.2.47 の新機能

## 🛡️ Windows インストーラがコード署名されました

ZUBOLAND株式会社のデジタル署名付きになり、インストール時の
SmartScreen「発行元不明」警告が解消されます（反映には数時間〜数日かかる場合があります）。

## 🔄 アップデートに自動で気づけるように

- 起動時にバックグラウンドで更新を自動チェックし、新しいバージョンが
  あるとメニューバー右上のボタンが緑色に変わります
- ボタンを押すと設定画面が開き、そのままアップデートを適用できます

## 🖥️ ターミナルの不具合修正

- **複数行テキストの貼り付けが崩れる問題を修正**
  （改行や空白が混ざって別々に送信されてしまう環境がありました）
- **長時間使っていると表示が崩れる問題を修正**
  （GPU リセットやスリープ復帰後に描画がズレたままになる場合がありました）

## 📦 AI CLI のインストール・更新を最新の公式手順に対応

- Claude Code / Codex の導入を各社の公式インストーラ優先に変更
  （Node.js が無いパソコンでもワンクリックで入ります）
- 「更新」ボタンが CLI 自身の自己更新（`claude update` / `codex update`）を
  使うようになり、二重インストール事故を防ぎます

## 🎨 チャット画面の改善

- 応答が空のまま「…」だけの吹き出しが積まれる問題を修正
- 右サイドバーの「キャラクター」表記を「モデル」に変更し、
  AI 切替の重複 UI を整理しました
