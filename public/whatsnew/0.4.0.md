# UNICREW 0.4.0 の変更

複数のAIを同じフォルダで働かせても壊れないようにする「並列を安全にする3点セット」と、
実装した本人ではない別の会社のAIに点検させる「相互監査」を入れました。
あわせて、0.3.3〜0.3.7 で入っていたのにお知らせできていなかった変更もここにまとめます。

## 🧱 AIごとに作業場を分ける（並列・議論モード）

- 2人以上のAIを同じフォルダで動かすとき、**AIごとに独立した作業場（git worktree）**を切るようにしました。
  これまでは4人のAIが同じファイルを同時に書き換えることがありました
- 右の「参加者」の下に、各AIのブランチ名と「取り込む」「パッチ」ボタンが出ます。
  取り込みで衝突したら自動では解決せず、止めて知らせます
- git 管理外のフォルダでは「git init する」ボタンが出ます（押すまでは今までどおり同じフォルダで動きます）

## 🔍 AIが何を変えたかを見る

- 右に「変更」ブロックが増えました。AIが動いた後に**変わったファイルの一覧と±行数**が出ます
- クリックすると、送る前と今のファイルを**左右に並べて比較**できます（読み取り専用）
- 「このターン」と「コミット後すべて」を切り替えられます。AIが新しく作ったファイルも数えます

## ⏪ 送る前の状態にファイルを戻す

- 自分の発言にマウスを乗せると「ここに戻す」が出ます。**その発言を送る直前の状態にファイルだけ戻します**
- 会話は消えません。コミット・ブランチ・ステージも動かしません。戻す直前の状態も記録するので、間違えても git から取り出せます
- **その時点より後に作られたファイルは削除されます**（確認画面にも出ます）。戻す範囲は「作業フォルダの中」だけで、その外は触りません

## 🛡️ 別の会社のAIに監査させる

- 送信欄で `/監査`（または右の「変更」の末尾のボタン）→ **実装したAIとは別の会社のAI**が読み取り専用で起動し、
  最後のコミット以降の変更を点検します（Claude が書いたら Codex が見る、逆も同じ）
- 点検のために、変更の差分（コードの本文）がその別の会社のAIに渡ります。使わなければ渡りません（[PRIVACY.md](https://github.com/takayukiyukii-commits/unicrew/blob/main/PRIVACY.md)）
- 観点は毎回1つ（コードの正しさ／表示と実装の一致／運用）で、前回と違う観点に自動で変わります
- 指摘は「指摘を実装AIに渡す」で、裏取りしてから直すよう指示付きで渡せます
- 別の会社のAIが接続されていないときは、同じ会社で続行しますが「自己点検に近い」と知らせます

## 💬 脇で相談する・過去の会話を探す

- `/side 質問` で、**本線の文脈を持ったまま脇のスレッド**で短く相談できます（読み取り専用）。
  「親に戻す」でその結論を本線の次の発言に前置きします。閉じても消えません（アーカイブ）
- `Ctrl+Shift+F` で全スレッドの題名と本文を検索し、そのメッセージへ飛べます。`Ctrl+F` はスレッド内検索です

## 🔒 UNIHUB連携のリモート受付を廃止

- スマホからの遠隔実行（UNIHUB経由）を機能ごと取りやめました。当社サーバーへ送るものは、
  匿名の起動情報3項目（乱数ID・バージョン・OS）だけに戻っています。詳しくは PRIVACY.md をご覧ください

## 📦 0.3.3〜0.3.7 で入っていた変更（お知らせが出ていなかった分）

- **0.3.7** 添付画像がAIに本当に届くようになりました（これまではファイルの読み取り許可で止まっていました）。
  Codex の Plan モードが起動直後に落ちる問題を直しました
- **0.3.6** Claude 経路で「出るはずの許可ダイアログ」が本当に出るようにしました
- **0.3.5** 存在しないプラグインを勧めていたのを修正しました（押すと必ず失敗するボタンでした）
- **0.3.4** 旧スマホ連携を完全に削除し、プラグイン追加の不具合3件を直しました
- **0.3.3** ターミナルの複数ページとセッション維持を直し、UNI一覧を刷新しました
- ブラウザ経路のAPIキーを本番では平文保存しないようにしました
- このお知らせ自体が5版ぶん止まっていたので、**版数がそろっていないと出荷できない検査**を入れました
