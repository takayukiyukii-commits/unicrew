# UNICREW 0.3.2 の変更

「ファイル」メニューの機能（チーム／ルーティーン／UNI-MCP 一括接続）を
ダブル監査（Claude×Codex×3回）で点検し、見つかった12件を修正しました。
機能の使い方は変わりません。安心して使えるようにするための更新です。

## ⏰ ルーティーン（定期実行）の直しどころ

- **作った瞬間に動いてしまう問題を修正**：たとえば夕方に「毎朝9時」のルーティーンを
  作ると、その場で1回実行されてしまうことがありました。これを止めました
- **「今すぐ実行」を押した日は、定時実行が二重に走らない**ようにしました
- スレッドを削除したルーティーンの「今すぐ実行」は押せないようにしました

## 🧩 チーム構成のインポートを頑丈に

- 壊れた保存データや、想定外のチームJSONを取り込んでも、チーム一覧や
  チーム作成が落ちないようにしました（不正なプロバイダは Claude に補正）
- 極端に大きいチームJSONを弾くようにしました

## 🔐 UNI-MCP 一括接続の安全性

- **切断すると、保存していた API キーもちゃんと消える**ようにしました
  （これまでは切断してもキーが端末に残っていました）
- 全切断が一部失敗したとき、これまでは黙っていたのを、失敗を知らせるようにしました
- 設定ファイル（~/.claude.json）の書き込みを「全部書けてから差し替える」方式にして、
  更新の途中で失敗しても壊れないようにしました
