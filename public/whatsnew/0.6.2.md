# UNICREW 0.6.2 の変更

作業が終わったときの**通知**を正確にし、**音声入力で送信**できるようにしました。
ターミナルの**読めない文字**と、タスクバーの**印の見た目**も直しています。

## 🔔 作業の通知が、終わった瞬間に1回だけ届きます

ターミナルの Claude Code が作業を終えたときの通知を作り直しました。

- これまでは画面の出力が止まったことから「終わったらしい」と推測していたので、作業の途中でも届くことがありました
- 0.6.2 からは Claude Code が出している「作業中」「止まった」の合図を見ます。終わってから約2秒で、1回だけ届きます
- 通知には**最後に送った指示**と、かかった時間が出ます（例：「ログイン画面を直して」（約3分））
- 許可の確認で止まったときは「確認を待っています」と、別の文面で知らせます
- 3秒未満の短いやりとりでは知らせません
- Claude Code 以外の AI は、これまでどおりの知らせ方です

## 🎙️ 「送信」と言うと送ります

音声入力の最後に「送信」と言うと、その言葉を消して送ります。チャットでもターミナルでも使えます。

- 「送信して」「送信してください」でも送ります
- 有効なのは、マイクのボタンを押してから5分間です（話すたびに延びます）。キーボードで「送信」と打っても送られません
- 「送信ボタンを直して」のように、途中にある「送信」では送りません

## 👀 ターミナルの質問が白い文字で読めない問題を直しました

明るい外観のとき、Claude Code が出す質問の選択肢が白い背景に白い文字で表示され、読めないことがありました。
背景との差が足りない文字は、自動で読める濃さで表示するようにしました。暗い外観では見た目は変わりません。

## 🔴 タスクバーの印を、小さくなめらかな丸にしました

終わった作業があるときにタスクバーと通知領域のアイコンに付く印の、縁のギザギザを無くしました。
大きさも一回り小さくしています。
